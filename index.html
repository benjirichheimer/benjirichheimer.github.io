Best Shooter Index: Rethinking How We Measure NBA Shooting

R · hoopR · tidyverse · Regression

Traditional metrics like eFG% and TS% reward rim-finishers, ranking players like Rudy Gobert above Stephen Curry. Using 2024-25 NBA play-by-play data, I built a custom shot-difficulty score that accounts for shot distance, step-backs, fadeaways, shot clock, clutch situations, and opponent defense. I combined it with efficiency to create a new index that finds the league's best perimeter shot-makers, then checked it against volume and efficiency benchmarks.
